BeCore Tickets for Android uses a permanent signing identity. Future releases update the installed app in place.

When moving from the original 0.1.0 debug APK, uninstall that initial app once, then install this release. Subsequent releases use Android's normal update installation. Event information refreshes from the live catalogue without an APK update.

Included: discovery, full event posters, event details, countdowns, native sharing and cached public event information. Ticket recovery, My Nights, notifications and checkout currently open the secure browser flow. Native authentication, private offline entry passes and native push remain under development. This release is not yet a Google Play submission.
